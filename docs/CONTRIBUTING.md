# Contributing to Vendor360

We welcome contributions to help empower local Kirana store owners!

## 🤝 Code Standards
- **Commit Messages**: Follow Conventional Commits format (`feat(...)`, `fix(...)`, `docs(...)`, `chore(...)`).
- **Translations**: Any new UI string must be added to all 4 locale files (`en.json`, `hi.json`, `mr.json`, `bn.json`).
- **Tests**: Ensure backend pytest (`pytest`) and frontend checks (`npm run i18n:check && npm run build`) pass before submitting.
