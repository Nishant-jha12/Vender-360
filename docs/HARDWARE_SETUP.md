# Vendor360 Hardware Integration Guide

Vendor360 works with standard retail POS peripherals out-of-the-box.

## 🖨 Supported Hardware
1. **Thermal Receipt Printers**:
   - USB / Bluetooth 58mm & 80mm ESC/POS printers.
   - Automatic receipt formatting via CSS print rules.
2. **Barcode Scanners**:
   - USB HID barcode scanners (emulates keyboard input).
   - Mobile camera scanning via WebRTC ZXing engine.
3. **Weighing Scales**:
   - RS232 / USB serial scales via Web Serial API.
