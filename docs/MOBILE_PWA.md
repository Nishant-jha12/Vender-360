# Vendor360 Mobile & PWA Guide

Vendor360 is engineered as a responsive progressive web application (PWA).

## 📱 Mobile App Features
- **Fluid Viewport**: Safe area padding and touch-first button targets (min 44px).
- **Native Navigation**: 4-tab bottom navigation with badge indicators.
- **Kirana App Drawer**: Bottom-sheet quick launcher for secondary utilities.
- **Local Network Access**: Connect phone to laptop running `--host 0.0.0.0:5173`.
