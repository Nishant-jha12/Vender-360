# Vendor360 Multi-Lingual Localization (i18n)

Vendor360 is built with native vernacular support for Indian retail storekeepers.

## 🇮🇳 Supported Languages

1. **English (`en`)**: Primary baseline locale.
2. **हिंदी (`hi`)**: Hindi translation with colloquial Kirana trade vocabulary.
3. **मराठी (`mr`)**: Marathi translation tailored for Maharashtra retail.
4. **বাংলা (`bn`)**: Bengali translation for Eastern India markets.

## 🔑 Key Structure

All locale files live under `frontend/src/locales/{code}.json` and are verified using `npm run i18n:check`.
Strict parity is maintained across all 277 UI keys.
