# Changelog - Vendor360

## [2.0.0] - 2026-09-11

### Added
- **Mobile-First App Redesign**: Native mobile frame, 4-tab bottom navigation, and Kirana App Drawer.
- **Light and Dark Theme**: Segmented Home screen toggle, top bar quick toggle, login screen toggle, and settings selector.
- **4 Vernacular Languages**: 100% complete Hindi, Marathi, Bengali, and English coverage across all 277 UI keys.
- **PWA Ready**: Web App Manifest and mobile viewport meta configuration.

### Enhanced
- **Quick Billing**: Faster barcode scanner integration with batch depletion.
- **Digital Khata**: One-click WhatsApp payment reminders with custom vernacular messages.
- **Security**: PBKDF2 password protection, JWT session controls, and remote session termination.
